# Simaran's Portfolio

A personal portfolio website built with React, Tailwind CSS, and Vite to showcase my skills, projects, and experience as a Full Stack Developer.

## Features

* Responsive design
* Light/Dark mode
* Skills showcase
* Project portfolio
* Contact section
* Fast performance with Vite

## Tech Stack

* React
* Tailwind CSS
* Vite
* Lucide React

## Installation

```bash
git clone <repository-url>
cd simaran-portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project can be deployed on:

* Vercel
* Netlify
* GitHub Pages
